⚙️ 핵심 프로세스

신청 프로세스 (Submit Request)

고객 선택 (1~3개)
검증 (개수, 중복, 마감 여부)
로컬: createRequest() / Supabase: RPC
저장 (localStorage / DB)
후보 저장 (version=1, priority)
성공 메시지 + 상태 갱신

확정 프로세스 (Confirm Request)

어드민이 고객의 희망 슬롯 선택
검증 (요청 존재, 유효성)
슬롯 마감 (status='confirmed')
다른 고객의 후보 확인
영향받은 고객 → 'needs_reselection'
기록 저장 + 결과 메시지

재선택 프로세스 (Resubmit Request)

고객이 'needs_reselection' 상태 확인
새 슬롯 선택 (1~3개)
검증 (개수, 중복, 마감)
version++ (이전 이력 보존)
상태 → 'received'
성공 메시지

🎯 서비스 접점

Front Stage (고객이 보는 부분)

접점 로컬 모드 Supabase 모드
진입점 localhost:5187/ /supabase
인증 역할 버튼 이메일 로그인
슬롯 표시 SlotTable (14행 × 3열)
신청 폼 선택 목록 + 버튼 RPC 호출
상태 조회 localStorage Supabase 쿼리

Back Stage (고객이 안 보는 부분)

계층 로컬 모드 Supabase 모드
저장소 localStorage (JSON) PostgreSQL
인증 In-memory Supabase Auth (JWT)
비즈니스 로직 operations.ts (메모리) RPC 함수
트랜잭션 JSON 복사 DB 잠금
